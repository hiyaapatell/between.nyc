# Between NYC

Colorful, responsive interactive NYC map website with route selectors and clickable hidden discoveries.

Built with HTML, CSS, JavaScript, Leaflet, and OpenStreetMap. Routing uses a public experimental endpoint; do not rely on directions for navigation. Time Peel and soundscapes are planned features.

## Publish
Go to **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
